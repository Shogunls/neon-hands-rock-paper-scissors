# Security Policy

## Supported version

Security fixes are provided for the latest `1.x` release only.

## Reporting a vulnerability

Do not open a public issue or publish working exploit code. The repository owner should enable GitHub Security Advisories and accept reports through **Report a vulnerability**.

Include the affected version, reproducible steps, expected and actual behavior, and potential impact. Do not include real user data, signing keys, credentials, or store secrets.

This project currently makes no bug-bounty commitment.
